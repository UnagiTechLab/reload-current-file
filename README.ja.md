# Reload Current File

[English](README.md) | 日本語

[![Ko-fi](https://img.shields.io/badge/Ko--fi-Support%20us-e11982?logo=ko-fi&logoColor=white)](https://ko-fi.com/unagitech)

ほかのアプリがファイルを書き換えたとき、開いているノートを読み直す Obsidian のプラグインです。

Obsidian は、外での書き換えをふだんは自分で見つけて表示を直します。ところが、ネットワークのドライブ（NAS・共有フォルダ）や一部の同期フォルダでは、その知らせが届かないことがよくあります。そのときは、ノートを開き直すか Obsidian を立ち上げ直すまで、画面が古い中身のままです。このプラグインは、いま見ているノートについて、これを直します。

## できること

- **自動の読み直し**：開いているノートを数秒おきに確かめ、ディスクのファイルのほうが新しければ読み直します
- **位置はそのまま**：カーソルとスクロールの位置は変わりません
- **手動の読み直し**：コマンド「いまのファイルをディスクから読み直す」。**設定 → ホットキー**でキーを割り当てられます
- **どちらの表示でも**：編集の表示（ライブプレビュー・ソースモード）と、閲覧の表示
- **日本語と英語**：Obsidian の言語の設定に合わせて切り替わります

## 設定

| 設定 | 最初の値 | 中身 |
|---|---|---|
| 自動で読み直す | オン | オフにすると、コマンドでだけ読み直します |
| 見張る間隔（秒） | 3 | 開いているノートを確かめる間隔。1〜60 秒 |
| 読み直したら知らせる | オン | 自動で読み直したときに、短い知らせを出します |

## 入れ方

**コミュニティプラグインから**（一覧に載ったあと）

1. **設定 → コミュニティプラグイン → 閲覧**
2. **Reload Current File** を探して**インストール**し、**有効化**する

**手で入れる**

1. [最新のリリース](../../releases/latest)から `main.js` と `manifest.json` をダウンロードする
2. `<Vault>/.obsidian/plugins/reload-current-file/` に置く
3. **設定 → コミュニティプラグイン**で、「インストール済みプラグイン」の横の再読み込みのボタンを押し、**Reload Current File** をオンにする

## 知っておいてほしいこと

- 確かめるのは、いま選んでいる画面のノートだけです。ほかのノートは、開いたときに新しい中身が出ます
- ノートに打っている途中に、ほかのアプリが同じファイルを書き換えると、外の書き換えのほうが残ります。まだ保存されていない最後の入力（たいていは直前の1〜2秒の分）が消えることがあります。同じファイルを2つのアプリで同時に直さないでください
- デスクトップ版だけで動きます

## プライバシー

このプラグインはネットワークにつながず、データも集めません。読むのは、Vault の中で開いているノートだけです。

# Reload Current File

**Unagi Tech Inc.（株式会社うなぎテック）** · MIT License

[English](README.md) | 日本語

[![Ko-fi](https://img.shields.io/badge/Ko--fi-Support%20us-e11982?logo=ko-fi&logoColor=white)](https://ko-fi.com/unagitech)

ほかのアプリがファイルを書き換えたとき、開いているノートを読み込み直す Obsidian のプラグインです。

Obsidian は、ほかのアプリによるファイルの変更を、ふだんは自動で検知して表示を更新しますが、ネットワークドライブ（NAS・共有フォルダ）や一部の同期フォルダでは、変更の通知が Obsidian に届かないことがあります。その場合、ノートを開き直すか Obsidian を再起動するまで、画面に古い中身が表示されたままになります。このプラグインは、いま開いているノートの更新を取得し、表示が古いままになるのを防ぎます。

## できること

- **自動の読み込み直し**：開いているノートを数秒おきに確認し、ディスクのファイルのほうが新しければ読み込み直します
- **表示位置の維持**：カーソルとスクロールの位置は変わりません
- **手動の読み込み直し**：コマンド「開いているファイルをディスクから読み込み直す」を使います。設定 → ホットキーで、キーを割り当てられます
- **編集、閲覧ビューに対応**：編集ビュー（ライブプレビュー・ソースモード）と閲覧ビュー
- **日本語と英語に対応**：Obsidian の言語の設定に合わせて切り替わります

## 設定

| 設定 | 初期値 | 内容 |
|---|---|---|
| 自動で読み込み直す | オン | オフにすると、コマンドを使ったときだけ読み込み直します |
| 確認する間隔（秒） | 3 | 開いているノートを確認する間隔。1〜60 秒 |
| 読み込み直したら通知する | オン | 自動で読み込み直したときに、短い通知を表示します |

## インストール

**コミュニティプラグインから**（Obsidian の審査を通り、コミュニティプラグインの一覧に載ったあと）

1. 設定 → コミュニティプラグイン →「閲覧」を開く
2. 「Reload Current File」を探してインストールし、有効化する

**手動でインストールする**

1. [最新のリリース](../../releases/latest)から `main.js` と `manifest.json` をダウンロードする
2. `<Vault>/.obsidian/plugins/reload-current-file/` に置く
3. 設定 → コミュニティプラグインで、「インストール済みプラグイン」の横にある再読み込みのボタンを押し、「Reload Current File」をオンにする

## 使うときの注意

- 確認するのは、いま選んでいるタブのノートだけです。ほかのノートは、開いたときに最新の中身が表示されます
- ノートを入力している途中に、ほかのアプリが同じファイルを書き換えると、ほかのアプリの変更で上書きされます。まだ保存されていない最後の入力（たいていは直前の1〜2秒の分）が消えることがあります。同じファイルを2つのアプリで同時に編集しないでください
- デスクトップ版のみ対応しています

## プライバシー

このプラグインはネットワークに接続せず、データも集めません。対象となるのは、Vault の中で開いているノートだけです。
